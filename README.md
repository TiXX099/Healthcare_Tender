# Healthcare_Tender
A bot designed to automatically collect and track healthcare sector tenders from various news sources and channels.

##  Key Features
* Automated Scraping: Continuously tracks and extracts tender announcements.
* Instant Alerts: Sends structured updates directly to a Telegram channel/bot.
* Data Filtering: Filters relevant opportunities specifically within the healthcare domain.
  
* ##  Tech Stack
* Python
* Telegram API
